# Python VTK 三维模型壳体拆分实验总结报告

## 📋 实验概述

本实验基于 Python VTK 库实现了三维模型的壳体拆分功能，能够自动识别和分离包含多个独立几何体的复合模型中的各个壳体组件。

## 🎯 实验目标

1. ✅ 实现基于连通性的壳体检测算法
2. ✅ 支持多种STL文件格式的读取和写入
3. ✅ 创建测试数据验证拆分功能
4. ✅ 提供可视化展示（支持交互式和离屏渲染）
5. ✅ 验证拆分结果的完整性和准确性

## 🔧 核心技术实现

### 主要功能模块

#### 1. 网格读取模块 (`read_mesh`)
- 支持STL、VTK、VTP等格式
- 自动检测文件扩展名并选择合适的读取器
- 错误处理和文件验证

#### 2. 网格清理模块 (`clean_mesh`)
- 合并重复顶点
- 修复网格拓扑结构
- 确保数据一致性

#### 3. 壳体提取模块 (`extract_all_shells`)
- 使用 `vtkPolyDataConnectivityFilter` 进行连通性分析
- 自动识别独立的连通组件
- 支持多种提取模式（全部区域、指定区域）

#### 4. 数据保存模块 (`save_shell`)
- ASCII格式STL输出
- 支持批量和单个文件保存

#### 5. 可视化模块 (`visualize_shells`)
- 多种颜色区分不同壳体
- 支持交互式3D显示
- HSV色彩空间自动分配
